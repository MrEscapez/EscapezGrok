# Permissions

- `escapezcore.command.*` / per-command nodes (incl. `escapezcore.command.report`)
- `escapezcore.staff` / `escapezcore.staffchat`
- `escapezcore.report.notify` — new-report alerts
- `escapezcore.report.manage` — `/reports` staff management
- `escapezcore.admin` (+ `.gui`, `.reload`, `.item`, `.item.give`, `.item.gui`)
- `escapezcore.cooldown.bypass`
- `escapezcore.scoreboard.toggle` — Toggle sidebar via `/sb` or `/ec scoreboard` (default true)

Without `escapezcore.admin`, `/ec admin` does not appear in tab or help.
