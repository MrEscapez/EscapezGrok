# Configuration

Main files in `plugins/EscapezCore/`:
- `config.yml` — prefix, database toggle, cooldowns, debug
- `messages.yml` — Dutch MiniMessage strings
- `commands.yml` — info command URLs (examples only)
- `aliases.yml` — soft alias map
- `gui.yml` — inventory layouts

Use `/ec admin reload` (requires `escapezcore.admin`) — **never** `/reload` / Bukkit reload.
