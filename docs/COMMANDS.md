# Commands

| Command | Description |
|---------|-------------|
| `/ec` | Opens main GUI |
| `/ec help` | Permission-filtered help |
| `/ec admin` | Admin tools (hidden without `escapezcore.admin`) |
| `/ec admin reload` | Soft-reload configs |
| `/discord` `/website` `/vote` `/shop` `/regels` `/staff` | Info links from commands.yml |
